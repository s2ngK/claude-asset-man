# 반응형 레이아웃

← [그룹 가계부](README.md) · 관련 [함정과 교훈](pitfalls.md)

한동안 모든 화면이 `max-w-md`(448px) 한 칸이었다. 폰에서는 맞지만 **브라우저에서 열면 넓은
화면 가운데 좁은 기둥 하나**만 보였다 → [#42](https://github.com/s2ngK/claude-asset-man/issues/42)

# 경계선은 `lg`(1024px) 하나다

브레이크포인트를 여러 개 두지 않는다. 이 앱의 화면은 "한 칸이냐 두 칸이냐" 로 갈리지
그 사이에 의미 있는 중간 단계가 없다.

| 폭 | 내비게이션 | 홈 | 통계 |
|---|---|---|---|
| `< lg` | 하단 탭바 | 위아래로 쌓임 | 위아래로 쌓임 |
| `>= lg` | 왼쪽 세로 바 | 요약·필터 \| 목록 두 칸 | 도넛 \| 추이 두 칸 |

**모바일이 기본값이다.** Tailwind 클래스에서 접두사 없는 쪽이 좁은 화면이고 `lg:` 가 넓은
화면이다. PWA 로 설치된 모바일 경험을 건드리지 않으려면 이 방향이어야 한다.

`AddEntryModal` 만 `sm`(640px)에서 갈린다 — 좁으면 아래에서 올라오는 전체 화면, 넓으면
가운데 뜨는 다이얼로그다. 넓은 화면에서 전체를 덮으면 뒤 목록이 사라져 **방금 무엇을 보고
있었는지** 잃는다.

# 내비게이션은 한 컴포넌트다

`src/components/AppNav.tsx` 가 두 모습을 다 들고 있다. 화면마다 따로 두면 항목이 어긋난다 —
실제로 홈과 통계가 각자 `<nav>` 를 복사해 갖고 있었다.

넓은 화면에서 아래를 가로지르는 바를 그대로 두지 않는 이유: 가로가 남는데 본문은 세로로만
길어지고, 눌러야 할 곳이 화면 반대편에 있다. 사이드바가 차지하는 폭은 `SIDEBAR_WIDTH`
상수(`lg:pl-56`)로 각 화면이 본문 왼쪽을 비운다.

> [!TIP] 현재 위치는 `usePathname` 으로 판단한다
> 화면이 "나는 홈이다" 를 넘겨주게 하면 넘기는 것을 잊은 화면이 생긴다.

# 함정: `overflow-hidden` 안에서는 `sticky` 가 어긋난다

넓은 화면의 목록을 카드처럼 보이게 하려고 `lg:rounded-2xl lg:overflow-hidden` 을 줬더니,
날짜 그룹 헤더(`sticky top-[73px]`)가 **자기 항목 아래로 내려가** 첫 줄과 헤더 순서가
뒤집혀 보였다.

`overflow: hidden` 인 조상이 있으면 그 안의 `sticky` 는 그 상자를 기준으로 동작한다.
넓은 화면에서는 목록이 이미 카드 경계로 구분되므로 **헤더를 띄울 이유가 없다** —
`sticky lg:static` 으로 껐다.

# 확인하는 법

크롬 확장은 **렌더링 뷰포트를 고정**한다. 창 크기를 바꿔도 `window.innerWidth` 가 그대로라
미디어 쿼리가 안 바뀐다. 좁은 폭을 확인하려면 **iframe 안에서 연다** — iframe 안의 미디어
쿼리는 그 iframe 폭을 본다.

```js
const f = document.createElement('iframe');
f.style.width = '390px'; f.src = '/';
document.body.appendChild(f);
// f.contentDocument 를 들여다보면 모바일 레이아웃이 보인다 (같은 오리진)
```

# 넓은 화면에는 다른 조작이 필요하다

같은 기능이라도 **입력 장치가 다르면 닿는 길이 달라야 한다.** 지금 갈라져 있는 것은
모달 닫기뿐이다 — 좁은 화면에서는 [닫기] 버튼, 넓은 화면에서는 바깥 클릭과 `Esc`.

# 아직 안 한 것

## 데스크톱에서 스와이프 삭제의 발견 가능성

스와이프는 포인터 이벤트라 마우스로도 끌리지만 (→ [삭제와 되돌리기](flow-delete-undo.md))
**끌 수 있다는 표시가 없다.**

행에 마우스를 올리면 삭제 아이콘이 드러나게 해봤다가 **되돌렸다.** 버튼이 자리를 차지하는데
그 버튼은 **자기 내역에만** 붙으므로, 목록에서 금액의 오른쪽 끝이 줄마다 어긋났다.

```
동료의 커피   2026-08-27 • 나          -₩4,800  🗑   ← 내 것: 버튼 자리만큼 밀림
첫 번째 지출  2026-08-27 • 테스터-01    -₩1,000       ← 남의 것: 끝까지
```

목록에서 **숫자가 세로로 맞지 않는 것**은 아이콘 하나 얻자고 치를 값이 아니다.
다시 한다면 버튼을 흐름에서 빼야 한다 — `absolute` 로 띄우거나, 자리를 **모든 행에**
항상 비워두거나.
